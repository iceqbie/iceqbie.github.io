Plasma Wave Workbench

Set a plasma once, and every tab answers a different question about it. Scales puts every frequency and length on a log axis, so you can see which orderings hold. Assumptions turns nine switches and shows which of 28 waves survive, which died, and exactly which term in the equations switched off to kill them. Selecting a wave in either tab carries it to the other.

Formulas are SI, non-relativistic, and quasineutral (ne = Z ni). The wave frequencies are the standard cold-plasma limits, except the ion-acoustic speed, which uses cs = √((Te + 3Ti)/mi). Lower hybrid uses ωLH−2 = (ΩeΩi)−1 + ωpi−2, not the geometric-mean shortcut — the shortcut is wrong whenever ωpe is not much larger than Ωe. Thermal speeds are √(T/m) with T in energy units. Every number here is reproduced by an independent Python implementation and checked against the NRL Plasma Formulary.

Real plasmas add drifts, anisotropy and more than one ion species, and warm corrections shift these numbers — treat the ladder as the order of magnitude, which is what it is for. Dispersion relations are shown in their standard limits; a mode listed here as separate can be one branch of a continuous surface in (ω, k, θ) space. Treat the matrix as the sorting rule it is, then check any specific claim in Chen ch. 4–7, Gurnett & Bhattacharjee ch. 4–9, or Stix for the cold-plasma modes.
